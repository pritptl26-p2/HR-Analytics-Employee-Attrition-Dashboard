# 📊 HR Analytics & Employee Attrition Dashboard

An interactive Power BI dashboard designed to analyze employee attrition, workforce demographics, salary, job roles, overtime, and employee satisfaction.


## 🔎 About the Project

The **HR Analytics & Employee Attrition Dashboard** is a data analytics project created to understand employee attrition and identify important workforce patterns.

The project uses employee data and an interactive **Power BI dashboard** to analyze factors such as department, job role, age group, overtime, job satisfaction, salary, and years at the company.

### Project Workflow

**Employee Data → Data Analysis → DAX Measures → Power BI Dashboard → HR Insights**



## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall employee attrition
- Calculate the employee attrition rate
- Analyze employee demographics
- Compare attrition across departments
- Analyze attrition by job role
- Analyze attrition by age group
- Understand overtime-related attrition
- Analyze employee job satisfaction
- Analyze average salary
- Analyze average years at company
- Create an interactive HR analytics dashboard



## 📁 Dataset

The project uses an employee dataset containing **1,000 records**.

### Dataset File

`HR_Employee_Attrition_1000.csv`

### Main Data Fields

- Employee ID
- Age
- Gender
- Department
- Job Role
- Job Level
- Monthly Income
- Years at Company
- OverTime
- Job Satisfaction
- Attrition

## 📈 Dashboard Visualizations

### 1. Attrition by Department

**Chart:** Column Chart

Used to compare employee attrition across different departments.

### 2. Attrition by Overtime

**Chart:** Donut Chart

Used to analyze attrition among employees who work overtime and those who do not.

### 3. Attrition by Job Role

**Chart:** Bar Chart

Used to identify job roles with higher numbers of employee attrition.

### 4. Attrition by Job Satisfaction

**Chart:** Column Chart

Used to analyze employee attrition across different job satisfaction levels.

### 5. Attrition by Age Group

**Chart:** Column Chart

Used to compare employee attrition across different age groups.



## 🎛️ Interactive Filters

The dashboard includes interactive filters for:

- Department
- Gender
- Job Role
- Overtime
- Job Level

These filters allow users to explore employee attrition from different perspectives.



## 📐 DAX Measures

DAX was used to create important HR analytics measures, including:

- Total Employees
- Total Attrition
- Attrition Rate
- Average Salary
- Average Years at Company

These measures make the KPI values dynamic and responsive to dashboard filters.



## 💡 Key Insights

The dashboard helps identify:

- Overall employee attrition levels
- Departments with higher employee attrition
- Job roles with higher numbers of employees leaving
- Attrition patterns across different age groups
- Overtime-related attrition patterns
- Employee job satisfaction patterns
- Average employee salary
- Average employee experience

This dashboard can help HR teams:
